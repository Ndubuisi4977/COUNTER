# Counter App

## About the Project
Counter App is a simple web application built to demonstrate basic JavaScript functionality. It allows users to increase, decrease, and reset a numerical counter.

## Features
- Increase the counter value.
- Decrease the counter value.
- Reset the counter to zero.
- Simple and user-friendly interface.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start using the counter.
